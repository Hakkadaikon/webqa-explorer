# 決めたことの記録

開発の途中で決めたことを、決めた日ごとに並べる。
決めたのが利用者なら「利用者」と書き、それ以外は開発を進めたセッションが brief やレビューの推す案から決めたものである。
仕様(feature か TLA+)を変えたものには「仕様」と書く。
各行の先頭の印は、その決定の状態を表す。

- 【済】main への PR に入った。
- 【後】決めただけで、実装は後続の issue で行う。括弧の中が受け持つ issue である。

利用者は、この一覧で決定を確かめ、変えたいものがあれば issue にする。
重要な決定は、決めたあとにサブエージェントにもレビューさせ、結果を各行に添える(利用者、2026-10-20)。
仕様の決定は loop-engineering-reviewer、設計の決定は reviewer が見る。TLA+ を変えたら modeler でモデル検査を通す。
